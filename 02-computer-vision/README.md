# Computer Vision

Turn images into useful predictions and inspect where models fail.

**Status:** learning area scaffold; no implementation or results yet.

## Starter project idea

Build a small waste-image classifier or visual defect detector.

This is an optional starting point. Choose a dataset with a clear source and suitable usage terms, and keep the first version small enough to run with available resources.

## What to practice

Inspect labels and class balance; separate related images across splits; compare a simple baseline with a pretrained model.

## How to evaluate

Report per-class performance and examples of mistakes. For detection, use detection metrics and inspect missed objects.

## What to publish

Create a named subfolder for each project. Include a completed README, data access instructions, runnable code or notebooks, an experiment log, and a concise explanation of results and limitations.

Start with the [project template](../docs/project-template.md) and [experiment log](../docs/experiment-log.md). See the [main README](../README.md) for the shared workflow.
