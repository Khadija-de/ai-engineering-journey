# Documentation templates

- [Project template](project-template.md): copy into a new project's folder as `README.md`.
- [Experiment log](experiment-log.md): copy into the same folder and add an entry for each meaningful experiment.

Replace bracketed prompts with your own information. Use “not yet measured” or “not applicable” when appropriate; do not leave example text looking like a real result. Keep a project's documentation close to its code.

Return to the [repository overview](../README.md).
